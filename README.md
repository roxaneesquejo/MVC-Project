# MVC-Project - Portfolio Page

## About
This repository is created as part of the requirements for **COMP 019 – Applications Development and Emerging Technologies**. It utilizes a Model-View-Controller design pattern and is built using ASP.NET Core MVC to showcase the authors' portfolio.
